# Convenzioni di denominazione

## 1. Nomi dei file

I nomi dei file devono seguire queste convenzioni:

- Utilizzare preferibilmente lettere minuscole. Sono ammesse eccezioni per i nomi convenzionali che richiedono le maiuscole, come `README.md`.
- Utilizzare i trattini (`-`) al posto degli spazi per separare le parole.
- Evitare spazi, caratteri speciali e abbreviazioni non standard.
- Mantenere le estensioni dei file in minuscolo.

## 2. Formato delle date

Le date devono essere espresse nel formato `AAAA-MM-GG`, dove:

- `AAAA` indica l'anno a quattro cifre.
- `MM` indica il mese a due cifre.
- `GG` indica il giorno a due cifre.

Il formato deve essere utilizzato in modo uniforme in tutti i documenti e nei nomi dei file che contengono una data.

## 3. Denominazione dei verbali

I verbali delle riunioni devono includere la data della riunione e un suffisso che ne identifichi la tipologia.

- **Verbali esterni**: utilizzare il formato `AAAA-MM-GG-ve`.
- **Verbali interni**: utilizzare il formato `AAAA-MM-GG-vi`.

Il nome del file deve terminare con il suffisso corrispondente alla tipologia del verbale, seguito dall'estensione del file.
